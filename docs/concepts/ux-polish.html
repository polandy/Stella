C12 — where to edit on touch

★ Faint pencil: every value that edits in place gets the name's pencil, faint (55 %), always shown on a coarse pointer and on hover elsewhere. One rule in §5.7, applied in InlineEdit, JobEdit and the facts that edit in place.

Dotted underline: the value is underlined in dots instead. Quieter, but it reads like a link or a spelling mark, and the name keeps a different sign (the pencil).
