Editing and deleting a circle

The circle page's header gets a ⋯ menu beside Open in the graph. Edit circle is for anyone who sees the circle. Delete circle… is for its creator, or an admin when it is shared. Every control below works: open the menu, edit and save, delete. The switches pick the state, and the URL keeps it, so every PNG is a link.

What to look at

  1. The ⋯ menu sits beside Open in the graph, as on a person's page. Signed in as Nina (a member who neither created this shared circle nor is an admin), it holds only Edit circle.
  2. Edit circle turns the header into a form in place: name, kind, description, colour, and the period, which the create form does not offer. Save closes it with Saved. The period then shows in the header line.
  3. Delete circle… opens the same sunken confirm step as deleting a person. It is not a modal. It counts what goes, says who keeps their profile picture, and names the circles inside that stay. Focus starts on Keep it.
  4. After the deletion you land on the Circles list with a toast and no Undo. Home's stream gets one line that links nowhere: Andy removed the circle Class 1B.

Decided (2026-10-10)

  1. Delete: the creator, or an admin when the circle is shared.
  2. Edit: name, description, kind, colour and period. Anyone who sees the circle.
  3. Confirm and an activity row, no Undo window.
  4. Circles inside it move up a level and keep everything.
