The identity card says each thing once

The facts are the only reading surface, and each is edited where it is read — as the job already is. The rows below keep only what has no fact: Contact (without the address), Tags and How we met. Tap a fact to edit it; tap + beside the circles to join one.

What changes

  1. One place per thing. The address is a fact only — the Contact row no longer repeats it. The circles are chips only — the folded Circles 3 · Join row is gone. Every date is a fact — the folded Dates 2 · Add row is gone, so the anniversary, which only that row showed, now stands beside the birthday.
  2. Tap a fact to edit it. Birthday or any date opens the dates (change, remove, add another); Address opens the address; Job works as today. The open editor takes the grid’s whole width, as the job’s form does now. Last contact is not editable — it follows the Activity card — and shows only when there is one (C5).
  3. + beside the circles joins one; the same editor lists the memberships, so a role is changed and a circle left there. The chips stay links to the circle.
  4. An empty fact waits behind the quiet button, which now names what is behind it (Add address, phone, email … for Kurt). Pressed, the empty facts appear in the grid as dashed slots — tap one to fill it — and the empty rows below. Switch Empty facts to compare with slots that are always there.
  5. Gender leaves the card — it moves into the name editor (C3), so no row is left that is neither a fact nor a list.

Demo data as seeded: Markus has no tags and nobody wrote how we met him, so those rows are behind the quiet button for him as well. Kurt has a birthday, a job and one circle — nothing else.
