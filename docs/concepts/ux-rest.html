A5 — tint strength per theme

The initials and chip labels stay in --fg, so the tint can only grow until --fg on it falls to 4.5:1. In Mocha the lightest accents (rosewater, yellow) reach that floor first: 32 % is already below AA for an avatar (4.24:1 rosewater), so the asked-for 32/24 and 40/30 are flagged ✗ and not offered for the build.

★ 28 / 22 / 28: Mocha's avatar and chip tints rise to the strength its active chip already has (28 %); the active chip stays 28 %, separated from a resting chip by weight as well as tint. Floor 4.76:1, the same as today's. Latte stays 22 / 16 / 28.

Ring: ★'s numbers plus a 1.5 px ring in the flat accent around an initials avatar. Identity without touching the text's ground; it does not help chips.

Side finding: in Latte today the active chip (28 %) on --bg is 4.11:1 for red — only on --card does it clear AA (4.87). The build adds the chip-on---bg pairing to color.test.ts.
