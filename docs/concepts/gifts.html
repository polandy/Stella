Geschenke: Ideen merken, Geschenktes nachlesen

Auf der Seite einer Person gibt es eine neue Karte Geschenke mit drei Tabs: offene Ideen, was wir geschenkt haben und was wir bekommen haben. Probier es aus: Notier eine Idee. Tipp „Teekanne“ ein, dann siehst du den Hinweis, dass sie schon geschenkt wurde. Markier eine Idee mit Verschenkt; danach steht sie auch unter Aktivität.

So wird umgesetzt: idea wird Idee, offered wird Geschenkt, und received wird Bekommen. Bisherige Kontakte der Art „Geschenk“ (Kontakt festhalten) werden ebenfalls zu Geschenken. Eine Notiz, die du nach dem Import bearbeitet hast, bleibt unverändert.
