# 05 — UI & Design System

Stella should feel **calm, warm, and effortless** — closer to a well-made notebook than a
CRM. This document defines the visual language, theming, layout, and interaction
patterns.

are grouped together); numbering and headings are unchanged by the split — a reference
like "docs/05 §5.8" resolves by opening the matching file below.
